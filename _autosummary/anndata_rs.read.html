anndata_rs.read#

anndata_rs.read(filename, backed='r+', backend=None)#

Read .h5ad-formatted hdf5 file.

Parameters:
filename Path

File name of data file.

backed Literal['r', 'r+'] | None

Default is r+. If 'r', the file is opened in read-only mode. If 'r+', the file is opened in read/write mode. If None, the AnnData object is read into memory.

backend Literal['hdf5', 'zarr']
