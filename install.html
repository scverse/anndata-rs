Installation#

You need to install rust first in order to compile the library, which can be accomplished by running:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Clone the source code repository and go to the python directory, use pip install . --use-feature=in-tree-build or python setup.py install to install the package.

git clone https://github.com/scverse/anndata_rs.git
cd python
pip install . --use-feature=in-tree-build
